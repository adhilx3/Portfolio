# Product

## Platform

web

## Stack

React + TypeScript + Vite + GSAP ScrollTrigger (selected by user for interactive project breakdowns, smooth scroll choreography, and zero-config Vercel deployment)

## Users

- **Primary:** MNC hiring managers, security recruiters, and internship leads evaluating Adhil Parokkot for InfoSec internships and junior security analyst / ethical hacker roles.
- **Secondary:** Adhil's Information Security institute trainer evaluating how well Adhil translates CEH and InfoSec fundamentals into structured, ethical software tools.

## Product Purpose

A personal portfolio website in Adhil Parokkot's name (`adhilparokkot.vercel.app`) that presents his identity, CEH/InfoSec learning progression, hands-on security engineering tools, and public GitHub repositories (`adhilx3`) so technical reviewers immediately recognize engineering discipline and ethical clarity.

## Positioning

Unlike generic student templates or "hacker" cliché sites, Adhil's portfolio leads with verifiable working security tools (SHA-256/VirusTotal desktop triage, heuristic URL phishing scoring, anti-raid Discord moderation, Nmap service enumeration, modular AI intent routing) paired with explicit legal and authorized-use responsibility.

## Operating Context

Visitors inspect on desktop and mobile browsers, skim hero credentials, scroll through project breakdowns, open technical architecture details, verify GitHub repositories and TryHackMe practice, and copy email or open LinkedIn/GitHub to reach out.

## Capabilities and Constraints

- Strictly anchored in a **black, white, and red** theme with **scroll-triggered animations** (GSAP + ScrollTrigger, respecting `prefers-reduced-motion`).
- Purely typographic and graphic presentation (no portrait photo or CV download button; primary CTAs point to projects, GitHub/TryHackMe proof, and direct contact).
- Live GitHub repository syncing (`https://api.github.com/users/adhilx3/repos`) backed by complete static fallback data.
- Preserve `#about`, `#projects`, `#skills`, and `#contact` section anchor IDs from `adhilparokkot.vercel.app`.
- Never fabricate completed certifications (CEH is *in preparation*, Advanced Diploma in Information Security is *in progress*), dates, institute names, or synthetic metrics.

## Product Principles

1. **Identity before index:** Adhil's name, mindset, and security judgment lead; repositories serve as proof.
2. **Evidence over theatrics:** Real architectures, real flags/checks, and honest learning status outperform neon hacker clichés.
3. **Resilient by default:** GitHub rate limits, offline viewing, or reduced-motion settings never break layout or hide content.
4. **Authorized & ethical clarity:** Security tools always carry clear legal/authorized-use framing.
