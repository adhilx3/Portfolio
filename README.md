## 🎯 Design Concept: Constructivist Security Monograph

Unlike generic developer templates or neon "cyber" clichés, this portfolio employs an editorial **Constructivist Security Monograph** design system:
- **Color Palette:** Stark polarity shifts between **Obsidian Black** (`#070709`) and **Paper White** (`#F6F5F1`), accented exclusively with **Signal Red** (`#E11D2E`).
- **Typography:** Architectural headings in `Barlow Condensed`, humanist reading body in `Work Sans`, and strict monospace data telemetry in `JetBrains Mono`.
- **Motion Grammar:** Continuous left-rail scroll progress spine, hero entrance choreography, and alternating section reveals powered by **GSAP** and **ScrollTrigger**.
- **Accessibility:** Full `prefers-reduced-motion` compliance, WCAG AA 4.5:1+ text contrast, keyboard focus traps on modals/drawers (`Tab` cycle & `Esc` exit), and resilient copy fallbacks.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/adhilx3/Portfolio.git
cd Portfolio

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` to explore the site with hot module replacement (HMR).

### Running Tests

```bash
npm test
```

Executes the Vitest test suite covering GitHub service resiliency, caching, fallback states, and React component rendering.

### Production Build

```bash
npm run build
```

Builds the optimized production assets into the `dist/` directory with TypeScript type-checking.
